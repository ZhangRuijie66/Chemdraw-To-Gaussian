# 高斯计算工具 · 便携版

把 ChemDraw 画的分子一键变成 Gaussian 输入文件（.gjf），并直接提交到北大高性能计算平台（教学二号等），
跑完还能把日志/结果读回来解析、画计算 UV-Vis 谱。
所有转换在本机完成，不联网、不上传数据；只有「上传并提交」时才连集群。

当前版本：**v0.6.1**（2026-10-25）

---

## 一、运行环境

- **Windows 10 / 11**
- **Python 3.10 或更高**（推荐 3.11）。安装时记得勾选 “Add python.exe to PATH”。
- 第一次运行需要联网（装依赖），之后可离线使用。

依赖说明（`启动.cmd` 会自动检查并安装）：

| 包 | 用途 | 是否内置 |
| --- | --- | --- |
| rdkit | 读 ChemDraw 结构、生成 3D 构象 | 首次运行自动装（约 25 MB） |
| numpy / matplotlib | 解析结果、画 UV-Vis 图 | 首次运行自动装 |
| paramiko | SSH 连接集群 | **已内置在 `高斯计算工具\vendor\`** |

---

## 二、启动

双击解压目录**根部**的 **`启动.cmd`**。

- 第一次会自动安装缺少的依赖（走清华镜像，需要网络）；
- 如果这是单独的 GitHub 源码 ZIP（上级没有共享 `_tools\hidden-launch.vbs`），
  启动器会自动改用本地模式，保留一个控制台窗口；便携版 zip 则直接运行；
- 装完后浏览器会自动打开界面（地址形如 `http://127.0.0.1:8795/`）；
- 关闭那个黑色命令行窗口即停止服务。

> 旧版快捷方式如果指向 `_tools\hidden-launch.vbs`，新版源码包已带兼容 shim；
> 但仍建议删除旧快捷方式，直接双击根目录的 `启动.cmd`。

如果浏览器没自动打开，手动访问命令行里打印的地址（默认 **http://127.0.0.1:8795/**）。

## 三、使用流程（以苯为例）

1. **选择目录**：左侧「ChemDraw 文件目录」选放 `.cdxml / .cdx / .mol` 的文件夹 → 点「扫描」；
2. **计算设置**：任务类型（opt freq / TD 单点 / 振动分辨…）、泛函（默认 PBE0）、基组（默认 def2-TZVP）、核数（32）、内存（160GB）；
3. **勾选分子**（扫描后默认全不选）→ 点蓝色「生成 .gjf」，默认写到 `输入目录\gjf`，底部预览区可看全文；
4. **超算提交**：
   - 集群选「教学二号」（分区 compute、QOS 留空、墙钟 2 天，会自动填好）；
   - 远程目录默认 `~/g16jobs`；
   - （可选）在「提交哪些分子」里勾分子；不勾就在提交时再挑文件；
   - 填学号、密码，点「登录（保持连接）」，输入手机 OTP 动态码（**只需一次**，之后连接保持）；
   - 点「上传并提交」→ 弹出文件选择面板（文件名/大小/修改时间）→ 确认 → 控制台显示 job id；
5. **查进度**：点「查询作业」看排队/运行中；也可以在最下面「命令行」里执行
   `squeue -u $USER`、`ls -lh *.log` 等命令；
6. **取结果**：
   - 「读取日志」→ 先列出远程日志（**带大小和修改时间**）→ 勾选 → 下载到 `输入目录\gjf\logs\`，
     右侧「计算结果」自动解析出状态、能量、是否优化收敛、虚频数、TD-DFT 激发态；
   - 「读取 chk」→ 勾选 `.chk`，工具会在集群上 `formchk` 转成 `.fchk` 再一起下载到 `输出目录\chk\`
     （`.fchk` 可用 GaussView / Multiwfn 打开）；
7. **画图**：结果表里点「UV-Vis 图」→ 生成 TD-DFT 计算 UV-Vis 谱并保存为 `<名字>_uvvis.png`；
8. **取消作业**：在最下面「取消作业」填作业号（空格分隔）→ `scancel`。

> 需要**先跑基态（opt）再跑 TD**：工具会自动先提交基态，再用 `--dependency=afterok` 提交 TD；
> 分两次提交时请手动加依赖：`sbatch --dependency=afterok:<基态jobid> job_xxx_td.sh`。

> 如果作业卡在 `DependencyNeverSatisfied`，说明它依赖的基态作业失败/被杀了，用「取消作业」取消后重提。

## 四、目录结构

```
高斯计算工具-可移植版\
├─ 启动.cmd                  ← 双击这个
├─ 使用说明.md
└─ 高斯计算工具\
   ├─ run.py                 ← 入口（网页 / --test / --make）
   ├─ gcalc\                 ← 核心代码（CDXML 解析、3D 生成、GJF 写出、SSH 提交、日志解析、画图）
   ├─ web\                   ← 网页界面
   ├─ vendor\                ← 内置的 paramiko（SSH 用）
   ├─ settings.json          ← 默认设置（可删，删了恢复出厂）
   ├─ README.md              ← 功能与关键词说明（泛函、基组、方法）
   └─ 开发记录.md
```

命令行也能用：

```bat
python 高斯计算工具\run.py --test                      :: 自检：扫默认 calculation 目录并生成
python 高斯计算工具\run.py --make 输入目录 输出目录       :: 批量转换
```

## 五、常见问题

**页面打不开？**
- 先看命令行窗口是否还在运行（关闭窗口=停服务）；
- 如果提示「工具已经在运行」，说明已经有一个实例，直接打开它打印的地址即可；
- 端口被占用时会自动换端口，注意看窗口里打印的 URL。

**提示缺少 rdkit / paramiko？**
重新双击 `启动.cmd`，它会自动装；也可以手动：
`pip install rdkit paramiko -i https://pypi.tuna.tsinghua.edu.cn/simple`

**`.cdx` 文件打不开？**
`.cdx` 是二进制格式，需要本机装 ChemDraw 才能转换；建议在 ChemDraw 里另存为 **`.cdxml`** 或 `.mol` 再用。

**连不上集群？**
- 必须在校园网内（或先连学校 VPN）；
- 平台不支持密钥登录，必须「密码 + OTP 动态码」；
- OTP 用一次即失效，登录成功后不用再输；连接断了才需要重新登录。

**重启工具后要重新输 OTP？**
是的，登录会话保存在服务进程里，关掉窗口/重启工具就断了；集群上已提交的作业不受影响。

**`opt freq` 跑一半被杀掉（日志停在 l1101）？**
大分子（如 β-胡萝卜素 96 原子）的频率计算很吃内存，可能被集群 OOM 杀掉。
报告只比 λmax 的话做 `opt` 就够；确实要 freq，把 `%mem` 降到 32–64 GB 或换小基组。

**分子优化出来是弯的、双键变顺式？**
2026-10-23 已修复：解析 CDXML 时会读出 ChemDraw 画的顺反，并默认把所有非环 C=C 强制成全反式
（花青、类胡萝卜素实验上都是全反式）。如果手上是旧版本生成的文件，重新「生成 .gjf」即可。

**计算吸收峰比实验偏蓝很多？**
TD-DFT 对花青类染料会系统性高估能隙（链越长误差越大，可达 0.5–0.6 eV），这是方法本身的局限；
可以用长程校正泛函（CAM-B3LYP / ωB97X-D）重算，或只比较同一系列的趋势。

**密码安全？**
密码和 OTP 只保存在内存里、只在当次连接使用，不会写入任何文件。

## 六、版本

当前：**v0.6.1**（2026-10-25）

主要功能：

- ChemDraw → 3D → .gjf（RDKit ETKDG + MMFF94，默认全反式）；
- 泛函 / 基组 / 任务类型目录，两步 TD、振动分辨（FC/HT）、单独 TD/freq 读 chk；
- 北大 HPC：密码 + OTP 保持登录、提交类型与分子筛选、afterok 作业依赖、提交包命名、
  **命令行执行**、**取消作业**、查询作业、日志先读取（带修改时间）再勾选下载、chk 转 fchk；
- 日志解析（状态/能量/收敛/虚频/TD 激发态）与 TD-DFT UV-Vis 作图。
